What the job does

  1. Read the PDF text.
  2. Segment it into one block per finding with the {{ job.scanner }} profile. This fixes the finding count.
  3. Extract: each block goes to the model, which returns one JSON record per block id. Missing ones are retried in smaller groups.
  4. Consolidate duplicates and normalise severity and CVSS.
  5. Export XLSX and CSV, one row per finding.
